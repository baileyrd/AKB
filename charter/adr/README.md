# Architecture Decision Records

ADRs capture durable architectural decisions that affect the AKB model,
evidence contract, generation pipeline, or governed project direction.

- Use `NNNN-short-title.md`, with immutable sequential numbers.
- Copy [`TEMPLATE.md`](TEMPLATE.md); do not edit the template for a decision.
- Superseded ADRs remain available and link to their replacement.
- A decision affecting generated data must identify schema, migration, and
  reproducibility consequences.
