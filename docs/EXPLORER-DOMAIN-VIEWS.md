# Explorer Domain Views

The generated explorer provides stable typed views at `#/view/layers`,
`packages`, `libraries`, `runtimes`, `toolchains`, and `repositories`. Each
view derives membership from entity kinds in the composed projection and links
back to canonical object routes. Empty views are intentional when the current
snapshot contains no matching typed objects.
