# Explorer Progressive Graph Expansion

Object pages initially render at most 25 incoming and 25 outgoing
relationships. When a direction has more edges, an explicit button reveals
the remaining neighbors; the same button collapses them again. The graph data
is not discarded—only the rendered neighborhood is bounded—so deep links and
relationship semantics remain stable.
