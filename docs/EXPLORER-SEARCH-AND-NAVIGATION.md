# Explorer Search, Filters, and Navigation

The generated explorer searches the composed graph locally by immutable ID,
display name, alias, and tag. It provides kind and status filters, a result
count, object cross-references through typed relationship links, and
breadcrumbs from Explorer to kind to the current object. Filtering changes the
view only; it does not modify the graph or omit matching evidence from the
underlying generated data.
