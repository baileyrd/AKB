# Generated Catalog Projection

`current.json` is created by `tools/import_package_catalog.py` and intentionally
is not hand-authored. It contains the latest verified repositories, packages,
environment membership, and dependency relationships.

The authored `model/graph.json` and generated `model/catalog/current.json`
compose the current architecture view. Historical projections are stored with
their source evidence beneath `evidence/snapshots/`.
