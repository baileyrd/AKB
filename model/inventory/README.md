# Generated Deep-Inventory Projection

`current.json` is generated by `tools/import_deep_inventory.py`. It contains
package-owned files, PE/COFF observations, DLL imports and exports, archive
members, development metadata, and build-recipe relationships.

The current projection is composed with `model/graph.json` and
`model/catalog/current.json` at validation and generation time. Raw snapshots
are evidence artifacts and are not intended for routine Git tracking.
